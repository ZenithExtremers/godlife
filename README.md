# GOD Life

麗澤大学の大学生活をまとめたスマホ用アプリ（PWA）です。GitHub Pages で公開します。

| タブ | 内容 | 元になったもの |
|---|---|---|
| ホーム | 今の授業・次の授業、家を出る時刻、課題、今日の学食 | — |
| カレンダー | 月表示＋選んだ日の一覧。大学の行事（`data/events.json`）・祝日・課題の締切・自分の予定（毎週くり返し可）を表示。上の切り替えで時間割（月〜土 × 1〜5限、スクショから読み込みも可） | 新規 |
| 課題 | 麗澤ポータル（UNIPA）の課題。GitHub Actions が自動で取得 | [ReiMind](https://github.com/ZenithExtremers/reimind) |
| 通学 | 「今出れば間に合う」。大学⇄南柏⇄柏乗換⇄荒川沖⇄家 | [LASTCALL](https://github.com/ZenithExtremers/lastcall) |
| 学食・教室 | 学食メニュー（`data/menu.json`）と空き教室検索（`data/rooms.json`） | 新規 |

ホームの「通学」には次の3つを出します（家にいそうな時間は行きを上、大学にいそうな時間は帰りを上に並べます）。

- **授業に合わせて**：次に授業がある日（今日の1コマ目がまだなら今日）の1コマ目に間に合うには、何時に家を出ればいいか
- **今から行くなら**：今から出ると何時に大学に着き、何限に間に合うか
- **今から帰るなら**：授業中なら、最後の授業が終わったあとに乗れる電車

**現在地**：通学タブの「📍 現在地」で、家・荒川沖・柏・南柏・大学から選ぶと、そこから先の経路で乗れる電車を出します（南柏→大学は徒歩、荒川沖→家は自転車だけ）。アプリを開いたとき・画面に戻ったときに1回だけ（5分に1回まで）位置を取り、一番近い地点を自動で選びます（場所が変わったときだけ知らせます。メニューでオフにできます）。「GPS」ボタンでもその場で取り直せます。位置の計算は端末の中だけで、どこにも送りません。GPS の誤差も見込んで判定し、3km以内なら一番近い地点を選びます。家の位置や、駅の位置がずれるときは「今いる場所を『◯◯』の位置として登録」でこの端末にだけ保存できます。現在地のボタンはホームの通学欄にもあり、駅にいるときは「次の授業に間に合うには」もその駅から計算します。選んだ現在地は3時間で「自動」（行きは家、帰りは大学）に戻ります。

**車内**：現在地の「車内」は、荒川沖〜柏の電車に乗っているときに使います。今走っている電車（出発済みで、着いてから15分以内）を候補としてすべて並べ、何時に着くか（授業に間に合うか）を出します。行きか帰りかは、移動中ならその向き、なければ車内になる直前の現在地、なければ時間割（最初の対面授業の前なら行き）で推定し、「逆向き」ボタンで切り替えられます。候補の「これに乗ってる」で、その電車の移動中カードを始めます。車内のときは「家を出た／大学を出た」は出しません。GPS では、駅の近くでなく荒川沖〜柏の線路沿い（2.5km以内）にいれば「車内」を選びます。

**移動中カードの手順**：手順をタップすると、そこまで終わったことにして、タップした時刻にその駅から乗れる一番早い電車で予定を組み直します（終わった手順をもう一度タップで1つ戻す）。最後の「着く」をタップすると終わります。

**表示の明るさ**：メニュー（☰）で「自動／ライト／ダーク」を切り替えられます（自動はスマホの設定に合わせる）。

**前後1本**：「今すぐ」では次の電車に加えて、1本前（出発時刻を何分過ぎたか）と1本後を出します。「到着時刻を指定」では、間に合う一番遅い電車に加えて、その1本前と1本後（遅れるなら何分遅れか）を出します。ホームの「今から行くなら／帰るなら」にも1本後を出します。

**天気**：ホームに、荒川沖（家の周り）と柏（大学の周り）の今日の天気・気温・朝夕の降水確率を出します（[Open-Meteo](https://open-meteo.com/)、APIキー不要。送るのは駅の位置だけ）。

**雨モード**：雨の日は荒川沖 ⇄ 家をバス（初期40分・待ち時間こみ）で計算します。通学タブの設定で「天気で自動（家の周りの6〜22時の降水確率が50%以上なら雨）／雨／晴れ」を選べます。

**シンプル表示**：大学に行く日の出発前（その日に対面授業があり、1コマ目の前で、家にいて、まだ「家を出た」を押していない／駅や大学に移動していない）だけ、アプリを開いたときに「あと◯分で家を出る」と次の授業を画面いっぱいに出します。タップでいつものホームへ。メニューでオン／オフできます。

**雨の日のバス**：並木大橋 ⇄ 荒川沖駅西口（関東鉄道）の時刻表を `data/bus.js` に入れると、雨モードのときはバスの時刻で計算します（家 ⇄ バス停は徒歩5分、バス ⇄ 電車の乗り換えは3分）。空のあいだは「バスで◯分」で計算します。

**出発前の通知**：メニューの「🔔 出発前の通知（ntfy）」でトピック名を入れると、アプリを開いたときに、次に家（大学）を出る時刻の◯分前の通知を ntfy に予約します（ntfy の予約配信。アプリを閉じていても届きます）。

**予定の行き先の駅**：カレンダーの予定に駅名を入れると、「荒川沖（またはその日の授業後なら南柏）からその時刻に着く経路」と「帰り」を Yahoo!乗換案内で開くボタンを出します。今日の予定はホームにも出ます。

**家を出た／大学を出た**：ホームの通学欄のボタン（家にいるときは「家を出た」、大学にいるときは「大学を出た」だけ。駅や車内では出ない）を押すと、押した時刻から乗れる電車をたどる「移動中」カードを一番上に出します。いま何をしているか、次の電車や乗り換えまであと何分か、到着予定、授業に何分前に着くか（遅れるなら何分遅れか）を表示します。「着いた」で終わり、着いて30分たつと自動で消えます。

**オンライン授業**：時間割の授業に「💻 オンライン」の印を付けると、その授業は家で受ける扱いになります。家を出る時刻は最初の対面の授業に合わせて計算し、オンライン授業の途中で出発になる場合は警告を出します。オンラインだけの日は通学の対象から外します。（スクショ読み込みでは、教室欄に「オンライン」「遠隔」「Zoom」などがあれば自動で印を付けます）

**2限の特例**：2限に行くときは、10:40 ちょうどに着く電車ではなく、荒川沖 9:14 発（大学 10:20 着）までの電車を選びます。通学タブの設定でオン／オフできます（`js/commute.js` の `SPECIAL`）。

## スクショから時間割を読み込む

時間割タブの「📷 スクショから時間割を読み込む」で、UNIPA などの時間割のスクショを読み取ります。
文字認識（[Tesseract.js](https://github.com/naptha/tesseract.js)）は端末の中で動くので、画像はどこにも送りません。初回だけ約3MBの日本語データをダウンロードします。

- 曜日（月〜金）が横、時限が縦に並んだ表の形と、「月曜 2限 ◯◯」が縦に並ぶ一覧の形に対応しています
- 読み取ったあと確認画面が出るので、まちがいを直してから保存します（文字が1〜2字抜けることがあります）

## 時限（2022年度からの100分授業）

1限 8:50–10:30 ／ 2限 10:40–12:20 ／ 3限 13:10–14:50 ／ 4限 15:00–16:40 ／ 5限 16:50–18:30
（`js/core.js` の `G.PERIODS` で変更できます）

## 公開のしかた

1. Settings → Pages → Source を **GitHub Actions** にする
2. Settings → Secrets and variables → Actions に次を登録する（ReiMind と同じ）

| 名前 | 中身 |
|---|---|
| `REITAKU_ID` | ポータルの User ID |
| `REITAKU_PW` | ポータルのパスワード |
| `KADAI_PASSPHRASE` | アプリで入れる合言葉（6文字以上。ポータルのパスワードとは別のもの） |
| `NTFY_TOPIC` | （任意）ntfy の通知用トピック名 |

3. `main` に push すると公開されます。その後は日本時間の 7・10・13・16・19・22時に課題を取りに行きます。
   Secrets が無いときは課題の取得だけを飛ばして、ほかの機能は公開します。

ReiMind と同じく、ログインに失敗すると自動更新を止めます（10回失敗でロックされるため）。
パスワードを直したら、Actions →「課題を更新して公開」→ Run workflow で `force` にチェックを入れて実行してください。

同じ `zenithextremers.github.io` で動くので、ReiMind の合言葉・完了の印と LASTCALL の徒歩・自転車の設定は、そのまま引き継がれます。

## バージョン

アプリのバージョンはメニュー（☰）の一番下に出ます。更新するときは `js/core.js` の `G.VERSION` と `sw.js` の `VERSION` をそろえて上げます。

## データの更新

- **学食**：`data/menu.json` の `days` に、`"2026-11-16": [{"name": "カレー", "price": 400}]` の形で入れる（`regular` は定番メニュー。`note` と `kcal` も書けます）
- **大学の行事**：`data/events.json` の `events` に `{"date": "2026-12-24", "end": "2027-01-06", "title": "冬季休業", "kind": "休業"}` の形で入れる（`end` は期間のときだけ。`kind` が「休講」「休業」などの日はカレンダーで色が付きます）
- **空き教室**：`data/rooms.json` の `rooms` に教室（`{"id": "か-301", "building": "かえで館", "cap": 40}`）を入れ、`busy` に `"曜日-時限"`（1=月）ごとの使用中の教室を入れる。
  アプリの「編集」で端末上で直してから「rooms.json の形でコピー」して貼り付けることもできます
- **電車の時刻表**：ダイヤ改正のときに `data/trains.js` を LASTCALL と同じ手順で作り直し、`sw.js` の `VERSION` を上げる
